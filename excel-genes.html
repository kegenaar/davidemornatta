← Humanity renamed genes because of Excel

In 2004, bioinformaticians started noticing that, when processing tabular datasets, some gene names were being changed inadvertently into non-gene names.

Upon investigation, the culprit turned out to be Excel's automatic type conversion. When Microsoft Excel imports or pastes data, it automatically guesses the data type of each cell. A string like "SEPT2" gets interpreted as 2-Sept. This is convenient for most users, but for biologists it's a complete disaster.

Imagine a molecular biology lab processing gene expression data. One column has:

  • TP53
  • BRCA1
  • SEPT2
  • MARCH1
  • GATA3

It gets transformed into:

  • TP53
  • BRCA1
  • 2-Sep
  • 1-Mar
  • GATA3

When the spreadsheet is later exported, downstream software no longer recognizes those genes. Instead of analyzing SEPT2 or MARCH1, the software simply sees dates and may ignore them, silently discarding important data. Researchers in 2016 scanned the leading genomics journals and revealed that approximately one-fifth of papers with supplementary Excel gene lists contained erroneous gene name conversions.

This also meant that a large number of widely used datasets contained corrupted data. Some of them probably are still used without awareness of the problem or without being fixed.

The funny turn of the story is that an uncommon decision was taken. To address the problem, in 2020 the HUGO Gene Nomenclature Committee decided to rename dozens of official human gene symbols so they could no longer be mistaken for dates.

Science adapted to the software.

Symbols like SEPT1 became SEPTIN1 to avoid the problem. And there is more, because, due to the above mentioned fact that millions of existing datasets still contained the old errors, researchers have created dedicated tools to repair them. Two examples are "Escape Excel" (2017), which prevents Excel from auto-converting problematic strings before import, and "Gene Updater" (2022), which automatically converts corrupted dates like "2-Sep" back into the correct modern gene symbols.

Jumping to the current times, the fix mentioned on HGNC FAQ page remains changing the cell formatting to text before importing the data.

TLDR: Humanity permanently changed some gene names because they did not parse well on Excel.
